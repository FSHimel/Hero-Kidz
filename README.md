# 🧸 Hero Kidz

**Hero Kidz** is a full-stack e-commerce web application built with **Next.js** for selling educational toys and products for children.

The project was built as a hands-on learning project while exploring the fundamentals of Next.js and modern full-stack web development.

## 🚀 Live Demo

🔗 **Live Website:** https://hero-kidzz-two.vercel.app/

## 📌 About The Project

Hero Kidz is an online toy store where users can explore products, view product details, add items to their cart, and manage their shopping experience.

While building this project, I focused on understanding how **Next.js works in a full-stack application**, rather than simply building a frontend with React.

This project helped me practice concepts such as routing, layouts, server-side functionality, authentication, database integration, API handling, and reusable components.

* 🛍️ Browse educational toys and children's products

## ⚙️ Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/hero-kidz.git
```

Navigate to the project:

```bash
cd hero-kidz
```

Install dependencies:

```bash
npm install
```

Create a `.env.local` file and add the required environment variables.

Then run the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
